# Student Management System

A full-stack student management application with a React frontend, Express REST API, and MongoDB persistence.

## Project structure

```text
test/
├── backend/
└── frontend-react/
```

## Requirements

- Node.js
- npm
- MongoDB

## Configuration

Create `backend/.env` from `backend/.env.example` and set `MONGODB_URI` and `PORT`.

Create `frontend-react/.env` from `frontend-react/.env.example` and set `VITE_API_BASE_URL`.

## Run everything

From this directory:

```bash
npm install
npm --prefix backend install
npm --prefix frontend-react install
npm run dev
```

Frontend: `http://localhost:5173`

API health: `http://localhost:5000/api/v1/health`

## Available root commands

```bash
npm run dev
npm run backend
npm run frontend
npm run build
npm run lint
npm run backend:start
npm run migrate:student-ids
```

## Core API

- `GET /api/v1/health`
- `GET /api/v1/students`
- `POST /api/v1/students`
- `GET /api/v1/students/:id`
- `PATCH /api/v1/students/:id`
- `DELETE /api/v1/students/:id`
- `GET /api/v1/dashboard/stats`

## Notes

Student IDs are generated by an atomic MongoDB counter and are unique and immutable. They are intentionally monotonic rather than gapless.

DOB is persisted as a MongoDB `Date` value; the frontend uses an HTML date input and normalizes the calendar date at the API boundary.
